# Prayer Times for desktop

Downloads of [Prayer Times](https://muazkadan.dev/prayer-times/) for Windows and Linux: prayer
times for your city, adhan alerts, the Qibla direction and a countdown to the next prayer in the
system tray, in English, Arabic, Turkish, Azerbaijani, German, Persian, French, Indonesian and Urdu.

## Install

Download the latest version from [Releases](https://github.com/muazkadan/prayer-times-releases/releases/latest):

- **Windows:** `PrayerTimes-<version>-windows-x64.msi`
- **Linux (x86_64):** `muazkadan-prayer-times-<version>-linux-x86_64.tar.gz`

Package managers (winget, the AUR) will be listed here as they become available.

## Feedback and bugs

Open an [issue](https://github.com/muazkadan/prayer-times-releases/issues) with your operating system
